# Requisitos parciais — HelpDesk API

Versão: rascunho 0.3 | Responsável: não informado | Data de aprovação: pendente

## Contexto

O sistema deverá permitir a gestão de chamados de suporte de uma empresa de médio porte. A solução deve ser simples, confiável e fácil de manter.

## Requisitos registrados

- RF-01: usuários poderão registrar chamados informando título, descrição e prioridade.
- RF-02: o sistema permitirá consultar chamados e filtrar por situação.
- RF-03: a equipe poderá atualizar o status dos chamados.
- RF-04: gestores poderão consultar indicadores de volume e resolução.
- RF-05: a aplicação permitirá exclusão de chamados conforme política interna (política não anexada).
- RNF-01: dados pessoais devem ser protegidos contra acesso indevido.
- RNF-02: mensagens de erro devem ser compreensíveis e não expor detalhes internos.
- RNF-03: o sistema deve preservar a integridade dos registros.

## Pontos em aberto

Critérios de aceitação; perfis e permissões; prazo de atendimento; lista formal de prioridades; significado de 'resolvido'; retenção e exclusão; desempenho esperado; regras para custos; trilha de auditoria; estratégia de testes.
